## Running it

Revived in 2026 to build and run natively on macOS, Linux, and Windows —
see [CONTRIBUTING.md](CONTRIBUTING.md) for setup. In short: `make run`.

**Login:** username `admin`, password `admin` — hardcoded; it's a college
test project, not a real system.

**Keys:** `Tab`/`Enter` moves between login fields, `ESC` backs out of
forms, menu `5` logs out, `Q` quits.

The original as-graded DOS build is preserved in the
[`college-submission`](../../releases/tag/college-submission) tag.
